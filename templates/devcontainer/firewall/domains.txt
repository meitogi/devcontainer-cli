# =============================================================================
# Project firewall allowlist — layer 2 of the 3-level model
# =============================================================================
# The base image already ships the universal sandbox minimum (Claude Code,
# VS Code, TLS plumbing, CVE lookup…) at
# /etc/devcontainer-firewall/domains.d/00-base.txt — layer 1. A fresh project
# needs NOTHING here : this file is additive, for the hosts YOUR project
# uses (its APIs, doc sites, registries beyond @anthropic-ai).
#
#   1. base image  domains.d/00-base.txt   — always present, sufficient alone
#   2. this file + domains.d/ + policy.d/  — committed project overlay
#   3. domains.local.txt + policy.local.d/ — gitignored personal overrides
#
# Overriding a base host from here (committed) :
#     !disable host.com                 # drop the base definition entirely
#     !disable host.com                 # …or drop AND redeclare narrower —
#     [GET] host.com                    # non-disable entries in the file
#       /my/scope/*                     # declaring the !disable survive
#
# -----------------------------------------------------------------------------
# Syntax — 5 formats
# -----------------------------------------------------------------------------
#   Format 1 — bare host (defaults: GET only)
#     docs.anthropic.com
#
#   Format 2 — methods inline (whole host)
#     [GET,POST] api.example.com
#
#   Format 3 — multi-line indented paths (EXACTLY 2 spaces, paths inherit
#              host-level methods; tab/1/3+ spaces = parse error)
#     [*] api.example.com
#       /v1/messages
#       /v1/files
#
#   Format 4 — single-line path + method
#     POST api.example.com/v1/messages
#
#   Format 5 — wildcard host and/or path
#     [POST] *.example.com                  # wildcard host (all subdomains)
#     [GET] api.github.com/repos/myorg/*    # trailing * = path wildcard
#
# -----------------------------------------------------------------------------
# domains.d/<eco>.txt — project deps per ecosystem
# -----------------------------------------------------------------------------
# compile-policy.py also walks firewall/domains.d/*.txt alphabetically and
# merges them ADDITIVELY (same-host entries across files = methods UNION +
# paths CONCAT). Typically generated by extract-auto-dependencies and the
# /scan-deps skill (domains.d/npm.txt, domains.d/composer.txt, …).
# The base image's own 00-base.txt lands in the same directory at bake time.
#
# In strict mode, add the L7 constraints for a new host in
# policy.d/<host>.yaml (committed) or policy.local.d/<host>.yaml (personal).
# =============================================================================

# copy policy.local.d.example/ollama.internal.yaml into policy.d/ (committed)
